TripMates — one HTML file, every screen visible (no hash URLs needed)
======================================================================

DEFAULT (what you asked for)
- Open **index.html** directly — even:
    file:///D:/projects/tripmates/prototype/index.html
- You get **one long page**: every app screen stacked + every popup/sheet listed below + bottom nav + toast.
- **Buttons and links do nothing** (safe for Figma / screenshots). **Scroll** to move through “pages.”
- No `#screen-…` in the URL required.

CLICKABLE DEMO (optional)
- Add **`?interactive=1`** to use the old prototype: one screen at a time, taps work.
- Examples:
    index.html?interactive=1
    index.html?interactive=1#screen-home
    index.html?interactive=1#screen-new-ride

LEGACY QUERY FLAGS (optional)
- `?figma=1` — same stacked layout as default (redundant now).
- `?static=1` — non-clickable only (stacked layout still needs figma-export; default already includes static).

FIGMA PLUGIN
- Use **html.to.design** with a **local server URL** if `file://` fails:
    http://127.0.0.1:5500/index.html
  (same “all screens” layout as double-clicking the file — no extra params.)
