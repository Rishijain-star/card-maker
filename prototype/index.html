Interactive demo — one screen at a time, buttons work. Start at Welcome or use a hash like #screen-home or #screen-flow-guide for the full journey map. For all screens on one page, open index.html without ?interactive=1.

Single file — all screens. Screens are grouped by flow (Authentication, Dashboard, Search & booking, Driver, Profile). Within each group, frames run left to right. Related popups sit below their screen with a connector arrow. Nothing is clickable (safe for Figma import & screenshots). Import with html.to.design (use a local server URL if the plugin cannot read file://). Design tokens: css/tripmates.css. Clickable app: add ?interactive=1 to the URL (optionally #screen-login etc.).
